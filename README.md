> 古典日本語の文法でプログラミングする。
>
> ブラウザで今すぐ試す（揃へ方不要）: https://rtck-reina.github.io/wabun-lang/
>
> 完全和文（文語調）版の案内は [読本.md](読本.md) を見よ。

漢文（中国古典）を構文に持つ [wenyan-lang](https://wy-lang.org/) の和文版にあたる難解言語。係り結び・助動詞・助詞による格表示を構文要素として写し取り、コードがそのまま擬古文として読めることを目標とする。JavaScript に翻訳して実行する。

```
※ Hello World ※
「世界」を書きけり。
```

```
※ FizzBuzz ※
一より十五まで n を一つずつ増しつつ、
　n を 三 にて割りたる余り、零に等し、且つ n を 五 にて割りたる余り、零に等しならば、
　　「FizzBuzz」を書きけり。
　然らずして、n を 三 にて割りたる余り、零に等しならば、
　　「Fizz」を書きけり。
　然らずして、n を 五 にて割りたる余り、零に等しならば、
　　「Buzz」を書きけり。
　然らずば、
　　n を書きけり。
　然らば終はり。
繰り返し終はりぬ。
```

## できること

- 漢数字直書（一〜京まで合成可、`三・一四` のような小数も可）
- 文字列直書 `「〜」`
- 真偽（`真` / `偽`）と空（`無し`）
- 集合（配列）直書 `〔一、二、三〕` または `集ひ：…、集ひ終はり`、要素の更新・削除・先頭/末尾の追加除去
- 録（連想配列）直書 `録：「鍵」は値、…、録終はり`、`obj の「鍵」` で参照、鍵の更新・削除
- 括弧 `（…）`（半角 `()` も可）
- 変数宣言 `〈式〉を 名 と云ふ。` と再代入 `名 に〈式〉を改む。`
- 算術（加・減・乗・除・剰余）と文字列連結
- 比較（等し・異なり・大なり・小なり・劣らず・勝らず）
- 論理（且つ / 或いは / に非ず）
- 条件分岐（`〜ならば、… 然らずして 〜ならば、… 然らずば、… 然らば終はり。`）
- 範囲反復（`一より十まで n を一つずつ増しつつ、… 繰り返し終はりぬ。`）
- 条件反復（`〜なる間、… 繰り返し終はりぬ。`）
- 各々反復（`配列 の各々を n と為して、… 繰り返し終はりぬ。`）
- 業（関数）定義（`a と b を受けて返す業を 名 と云ふ。… 業終はりぬ。`）と再帰呼び出し
- 例外処理（`試みに、… 過つに、e を以て、… 試み終はりぬ。` と `〈式〉を投ぐ。`）
- 読み入れ（`「path」を読み入れけり。` 循環検出付き、卓上のみ）
- 入力（`名 に問ひけり。`）と出力（`〈式〉を書きけり。`）
- 標準ライブラリ40+の業：算術・三角関数・対数・冪／数学定数（円周率・自然底）／乱数／文字列（部分・整ふ・冒頭・末尾・探す・置換・大文字化・小文字化）／集合（並べ替へ・降順・含む・結ぶ・分かつ・末尾追加除去・先頭追加除去・空）／高階関数（写し替へ＝map・選び出し＝filter・束ね＝reduce・巡らす＝forEach・一切＝every・孰れか＝some）／録（鍵列挙・値列挙）／日付（今・日付・時刻）／変換（数値化＝漢数字対応・文字列化・型）
- 完全和文化された誤りメッセージ（`構文解析誤り：『を』を期待せしも『ならば』来たり（位置 7:28）` ＋ ソース該当行と矢印付き脈絡表示）
- 卓上実行・JS翻訳・対話処（REPL）・閲覧場（Webプレイグラウンド）

## 揃へ方

```bash
git clone https://github.com/RTCK-reina/wabun-lang.git
cd wabun-lang
# Node.js 18+ を要す。依存ライブラリは無し。
```

## 用ひ方

### 卓上で実行

```bash
node bin/wabun.js run examples/fizzbuzz.wb
```

### JavaScript に翻訳

```bash
node bin/wabun.js compile examples/factorial.wb -o factorial.js
```

### 構文木を覗く（試走用）

```bash
node bin/wabun.js ast examples/hello.wb
```

### 対話処

```bash
node bin/wabun.js repl
> 三を 値 と云ふ。
> 値 に （値 に 一 を加へたる）を改む。
> 値 を書きけり。
4
> やめ
```

### 閲覧場（ブラウザ）

公開版がある。揃へずとも触れる：https://rtck-reina.github.io/wabun-lang/

手元で動かす場合：

```bash
# まず束ねを生成
npm run build   # = node scripts/build-playground.js
# あとは playground/index.html を閲覧器で開くだけ
open playground/index.html
```

`dist/wabun.bundle.js` は `src/` から生成される成果物であり、リポジトリに commit されている。`src/` に手を入れたら `npm run build` を実行して `dist/` も併せて commit すること（CI が乖離を検出して落ちる）。

機能：

- 和紙風意匠、墨・朱・苔・紺の四色構文ハイライト（即時反映）
- 入力中の自動実行（350ミリ秒の溜め）
- 結果／構文木／成果文／字句列の四面切替
- 縦書き表示の切替（古文として読みたいとき用）
- コードを含む経路（URL）での共有（`#c=...` で位置情報に格納、按鈕一つで写し取り）
- `⌘ もしくは ^ + Enter` で即実行
- `Tab` で全角空白挿入（字下げ用）
- 14個の例題（基礎構文 → 高階関数 → 例外 → 数当て・じゃんけん・古文クイズまで）
- 入力を要する `問ひけり` を含むコードは自動実行を控へ、明示的な実行で `prompt()` を起動

### 倉庫として用ひる

```js
import { runSource, compileSource } from './src/index.js';

await runSource('「世界」を書きけり。', {
  writeLine: (s) => console.log(s),
});

const js = compileSource('三を 値 と云ふ。 値 を書きけり。');
console.log(js);
```

## 言語の手触り

### 変数宣言と算術

```
三を 値甲 と云ふ。
四を 値乙 と云ふ。
値甲 に 値乙 を加へたる を書きけり。   ※ 7 ※
値甲 に 値乙 を掛けたる を書きけり。   ※ 12 ※
十 を 三 にて 割りたる余り を書きけり。 ※ 1 ※
```

| 古文表現 | 意味 |
|---|---|
| `A に B を加へたる` | A + B |
| `A より B を引きたる` | A - B |
| `A に B を掛けたる` | A * B |
| `A を B にて 割りたる` | A / B |
| `A を B にて 割りたる余り` | A % B |
| `A に B を継ぎたる` | 文字列連結 |

### 比較と論理

```
値、五に等し       ※ === ※
値、五より大なり    ※ > ※
値、五に劣らず     ※ >= ※
値、五に非ず       ※ != ※（左辺の真偽反転は「Expr に非ず」）
A、且つ B          ※ && ※
A、或いは B         ※ || ※
```

### 括弧

算術の優先順位は同レベル左結合。優先順位を変へたいときは `（）` で明示する。

```
（三 に 四 を加へたる）に 五 を掛けたる を書きけり。   ※ 35 ※
三 に （四 に 五 を掛けたる）を加へたる を書きけり。   ※ 23 ※
```

### 録（連想配列）

```
録：「名」は「太郎」、「年」は二十、録終はり を 人 と云ふ。
人 の「名」を書きけり。   ※ 太郎 ※
人 の「年」を書きけり。   ※ 20 ※
```

### 標準ライブラリ

```
絶対値 に 負の七 を奉りたる を書きけり。              ※ 7 ※
最大 に 〔三、一、四、一、五、九〕 を奉りたる を書きけり。 ※ 9 ※
逆順 に 「いろはにほへと」 を奉りたる を書きけり。      ※ とへほにはろい ※
結ぶ に 〔「松」、「竹」、「梅」〕 と 「・」 を奉りたる を書きけり。  ※ 松・竹・梅 ※
数値化 に 「一万二千三百四十五」 を奉りたる を書きけり。   ※ 12345 ※
```

### 高階関数

ユーザ定義の業を引数として渡せる。

```
n を受けて返す業を 二倍 と云ふ。
　n に 二 を掛けたる を返すなり。
業終はりぬ。

写し替へ に 〔一、二、三、四、五〕 と 二倍 を奉りたる を書きけり。
　※ 〔2、4、6、8、10〕 ※
```

### 例外処理

```
試みに、
　「危ない事よ」を投ぐ。
過つに、e を以て、
　「捕まへたり：」 に e を継ぎたる を書きけり。
試み終はりぬ。
　※ 捕まへたり：危ない事よ ※
```

### 読み入れ

```
※ examples/lib.wb ※
n を受けて返す業を 二倍 と云ふ。
　n に 二 を掛けたる を返すなり。
業終はりぬ。

※ main.wb ※
「./lib.wb」を 読み入れけり。
二倍 に 五 を奉りたる を書きけり。   ※ 10 ※
```

### 配列・録の要素操作

```
〔一、二、三〕を 数 と云ふ。
数 の 二 番目 に 二十 を改む。
数 を書きけり。   ※ 〔1、20、3〕 ※
数 の 一 番目 を削る。
数 を書きけり。   ※ 〔20、3〕 ※

録：「名」は「太郎」、録終はり を 人 と云ふ。
人 の「年」に 二十 を改む。
人 を書きけり。   ※ 録：「名」は太郎、「年」は20、録終はり ※
```

### 業（関数）定義（再帰階乗）

```
n を受けて返す業を 階乗 と云ふ。
　n、一に勝らずならば、
　　一を返すなり。
　然らば終はり。
　階乗 に （n より 一 を引きたる）を奉りたる を 下 と云ふ。
　n に 下 を掛けたる を返すなり。
業終はりぬ。

階乗 に 五 を奉りたる を書きけり。  ※ 120 ※
```

呼び出しは「`f に 引数 を奉りたる`」（式）または「`f に 引数 を奉りけり`」（文）。

## 影詞（かげことば）— GLSL fragment shader バックエンド

派生バックエンド。同じ和文構文で fragment shader が書け、`wabun compile-影詞` で GLSL ES 1.00 に翻訳される。プレイグラウンドの「影詞」按鈕で WebGL リアルタイムプレビューに切替。

```
※ 虹色グラデーション ※
受けて返す業を 主 と云ふ。
　時 に 〇・五 を掛けたる を t と云ふ。
　〔
　　正弦 に （uv の「横」 に t を加へたる）を奉りたる、
　　余弦 に （uv の「縦」 に t を加へたる）を奉りたる、
　　〇・五、
　　一
　〕 を返すなり。
業終はりぬ。
```

詳細は [docs/影詞-SPEC.md](docs/影詞-SPEC.md) を参照。

## 構成

```
wabun-lang/
├── src/
│   ├── lexer.js      字句解析器（漢数字解析・予約語最長一致）
│   ├── parser.js     再帰下降構文解析器（係り結び・助動詞構造を構文木化）
│   ├── compiler.js   構文木 → JavaScript 翻訳器
│   ├── runtime.js    実行時下働き（出力・型変換・索引参照 等）
│   ├── builtins.js   組み込み業（絶対値・部分・並べ替へ 等）
│   └── index.js      公開窓口（runSource, compileSource）
├── bin/
│   └── wabun.js      卓上（CLI、run / compile / ast / repl）
├── playground/
│   └── index.html    閲覧器用の遊び場
├── examples/         例題（.wb）
├── docs/
│   └── SPEC.md       言語仕様書
├── scripts/
│   └── build-playground.js  遊び場用の束ね生成器
└── test/
    └── run.js        記録試験
```

## 設計上の判断

- **識別子は鉤括弧で囲まない。** 文字列直書との区別を明確にするため。例：変数名は `年齢`、文字列は `「年齢」`。
- **演算子優先順位は単純化。** 算術＜比較＜AND＜OR の階層は保つが、算術内部は同レベル左結合（`A に B を加へたるに C を掛けたる` は `(A+B)*C`）。明示的なまとめ括弧 `（）` で優先順位を変えられる。
- **目的言語は JavaScript のみ。** 配布は翻訳方式。`async` を使うため、Node.js 18+ 必須。
- **予約語辞書は最長一致。** `繰り返し終はりぬ` と `終はりぬ` のような曖昧性は、辞書を長い順にソートして解決。
- **内部識別子は `_和_` 接頭辞、ランタイムは `__和__`。** ユーザ定義の名前空間と衝突しないよう全和文の接頭辞を採用。

## 限界・未対応

- BigInt（京以上の整数の安全な表現）
- 生成業／yield／async 制御
- マクロ・メタプログラミング
- 標準入力以外のシステムコール（ファイル読み書き、網絡）— 必要なら JS に翻訳してから実装する想定
