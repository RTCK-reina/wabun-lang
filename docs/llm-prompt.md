# 和文 (wabun-lang) — LLM 用完全指南

このファイルを LLM（Claude / GPT / Gemini 等）のシステムプロンプトに丸ごと貼り付けるか、`和文ライブラリ準拠で書け` と指示した上でこのファイルを与えると、和文 (wabun-lang) のコードを正しく書けるようになる。

## 0. ひと言サマリ

和文 (wabun-lang) は古典日本語（文語体）の文法を構文として用いる難解言語。JavaScript に翻訳して実行される（影詞モードでは GLSL fragment shader に翻訳）。文末は必ず句点「。」、文字列は `「〜」`、識別子は鉤括弧で囲まない、ブロックは終端マーカー（`〜終はり` / `〜終はりぬ`）で閉じる。

ファイル拡張子：和文は `.wb`、影詞（GLSL）は `.kg`。

## 1. 絶対規則（これを破ると即パースエラー）

1. すべての文の終端は **半角ピリオドではなく全角句点「。」**
2. 文字列リテラルは **半角引用符ではなく鉤括弧 `「〜」`**
3. 識別子（変数名・業名）は **鉤括弧で囲まない**。囲むと文字列リテラルになる
4. 配列リテラルは **半角ブラケットではなく `〔 〕`**
5. 録（連想配列）リテラルは **`録：` で開始、`録終はり` で閉じる**
6. グルーピング括弧は **半角 `()` でなく全角 `（）`**（半角も一応動くが全角推奨）
7. 句読点は **全角 `、` `。`**
8. ブロックは終端マーカーで明示：if は `然らば終はり`、ループは `繰り返し終はりぬ`、業（関数）は `業終はりぬ`、try は `試み終はりぬ`、配列直書は `集ひ終はり`、録直書は `録終はり`
9. 比較式は左右を **読点 `、` で区切る**（例：`値、五に等し`）
10. 業の引数で複合式を使うときは **必ず全角括弧で囲む**

## 2. リテラル早見

| 書き方 | 意味 |
|---|---|
| `〇` `零` | 0 |
| `一` `二` `三` ... `九` | 1〜9 |
| `十` `百` `千` `万` `億` `兆` `京` | 10、100、1000、1万、1億、1兆、1京 |
| `二十三` | 23 |
| `一万二千三百四十五` | 12345 |
| `三・一四` | 3.14（中黒で小数） |
| `負の三` | -3 |
| `123` `3.14` | 半角数字も可 |
| `「文字列」` | string |
| `真` / `偽` | true / false |
| `無し` | null |
| `〔一、二、三〕` | [1, 2, 3] |
| `集ひ：「春」、「夏」、集ひ終はり` | 配列の別記法 |
| `録：「名」は「太郎」、「年」は二十、録終はり` | {名: "太郎", 年: 20} |

## 3. 構文早見

### 変数宣言
```
〈式〉を 名 と云ふ。
```
例：`三を 値 と云ふ。`（let 値 = 3;）

### 再代入
```
名 に 〈式〉を改む。
```
例：`値 に 五 を改む。`

### 出力
```
〈式〉を書きけり。
〈式〉を詠みけり。   ※「詠みけり」 も同じ意味※
```

### 入力（標準入力／プロンプト1行）
```
名 に問ひけり。
```

### 算術（同レベル左結合、優先順位は `（）` で明示）
| 構文 | 意味 |
|---|---|
| `A に B を加へたる` | A + B |
| `A より B を引きたる` | A - B |
| `A に B を掛けたる` | A * B |
| `A を B にて 割りたる` | A / B |
| `A を B にて 割りたる余り` | A % B |
| `A に B を継ぎたる` | 文字列／配列の連結 |

### 比較（左右を読点で区切る）
| 構文 | 意味 |
|---|---|
| `A、B に等し` | A === B |
| `A、B に異なり` | A !== B |
| `A、B より大なり` | A > B |
| `A、B より小なり` | A < B |
| `A、B に劣らず` | A >= B |
| `A、B に勝らず` | A <= B |

### 論理
| 構文 | 意味 |
|---|---|
| `A、且つ B` | A && B |
| `A、或いは B` | A \|\| B |
| `A に非ず` | !A（後置） |

### 条件分岐
```
〈条件〉ならば、
　〈処理〉
然らずして、〈条件2〉ならば、
　〈処理〉
然らずば、
　〈処理〉
然らば終はり。
```

`然らずして` と `然らずば` は省略可。最低形は `〈条件〉ならば、〈処理〉然らば終はり。`

### 範囲反復
```
〈始〉より〈終〉まで 名 を一つずつ 増しつつ、
　〈処理〉
繰り返し終はりぬ。
```
両端を含む（例：`一より十まで` は 1〜10）。`増しつつ` を `減じつつ` にすれば逆順。

### 条件反復
```
〈条件〉なる間、
　〈処理〉
繰り返し終はりぬ。
```

### 各々反復（forEach）
```
配列 の各々を 名 と為して、
　〈処理〉
繰り返し終はりぬ。
```

### 業（関数）定義
```
引数1 と 引数2 を受けて返す業を 名 と云ふ。
　〈処理〉
　〈式〉を返すなり。
業終はりぬ。
```
引数なし：
```
受けて返す業を 名 と云ふ。
　〈処理〉
業終はりぬ。
```

### 業呼び出し
| 構文 | 意味 |
|---|---|
| `名 に 引数 を奉りたる` | 式として呼ぶ |
| `名 に 引数 を奉りけり` | 文として呼ぶ |
| `名 に 引数1 と 引数2 を奉りたる` | 複数引数 |
| `名 に を奉りたる` | ゼロ引数 |
| `名 に （複合式）を奉りたる` | 引数が複合式の場合は必ず括弧 |

### 配列・録の操作
```
配列 に 値 を加ふ。              ※ 末尾追加（破壊的）
配列 の 三 番目 に 値 を改む。     ※ 索引代入
配列 の 一 番目 を削る。          ※ 索引削除
録 の「鍵」に 値 を改む。         ※ 鍵代入
録 の「鍵」を削る。              ※ 鍵削除
```

### アクセス
| 構文 | 意味 |
|---|---|
| `配列 の 三 番目` | 配列[2]（1始まり） |
| `配列 の総数` | 要素数 |
| `配列 の「鍵」` | 録の値（文字列リテラルキー） |
| `文字列 の長さ` | 文字数 |

### 例外処理
```
試みに、
　〈処理〉
過つに、e を以て、
　〈処理〉
試み終はりぬ。
```
`e を以て` は省略可（既定で `過ち` という名で参照可能）。例外を投げるには：
```
〈式〉を投ぐ。
```

### 読み入れ（モジュール）
```
「path/to/file.wb」を 読み入れけり。
```
卓上（CLI）でのみ動作。閲覧場（playground）では未対応。

## 5. やってはいけない（LLM が踏みやすい罠）

### 5.1 識別子を `「」` で囲まない
誤：`「年齢」を 五 と云ふ。` ← 文字列リテラルになり、変数宣言の名前にならない
正：`五を 年齢 と云ふ。`

### 5.2 業の引数で複合式を裸で書かない
誤：`階乗 に n より 一 を引きたる を奉りたる`（曖昧で誤動作の可能性）
正：`階乗 に （n より 一 を引きたる）を奉りたる`

### 5.3 比較式の左右を読点で区切る
誤：`値 五に等し`
正：`値、五に等し`

### 5.4 ブロック終端を忘れない
- if → `然らば終はり`
- 範囲反復／条件反復／各々反復 → `繰り返し終はりぬ`
- 業 → `業終はりぬ`
- 試み → `試み終はりぬ`
- 集ひ → `集ひ終はり`
- 録 → `録終はり`

### 5.5 全角と半角を混ぜない
配列リテラル `〔 〕` `[ ]` 半角もあるが推奨は全角。鉤括弧は必ず `「 」`（半角の `"` `'` は使えない）。句点は `。`（半角 `.` は数値の小数点用のみ可、ただし慣習は中黒 `・`）。

### 5.6 配列インデックスは 1 始まり
`配列 の 一 番目` が最初の要素。0始まりではない。

### 5.7 範囲反復の上限は包含的
`一より十まで` は 1〜10（10を含む）。

### 5.8 関数を if ブロック内で `let` 宣言した変数は外から見えない
内部で宣言する変数は ifブロック内でしか使えない。外で使いたいなら if の前に `無し を 名 と云ふ。` で宣言しておき、内部で `に〜を改む` で再代入する。

### 5.9 影詞モード（.kg）では副作用禁止
`書きけり`、`問ひけり`、`改む` 系、`削る` 系、`加ふ`、`投ぐ`、`試みに`、`読み入れけり`、録、各々反復、条件反復は全て禁止。

```

　「小なり」を書きけり。

### 6.5 FizzBuzz
```
一より十五まで n を一つずつ増しつつ、
　n を 三 にて割りたる余り、零に等し、且つ n を 五 にて割りたる余り、零に等しならば、
　　「FizzBuzz」を書きけり。
　然らずして、n を 三 にて割りたる余り、零に等しならば、
　　「Fizz」を書きけり。
　然らずして、n を 五 にて割りたる余り、零に等しならば、

　然らば終はり。
繰り返し終はりぬ。
```

```

　n、二より小なりならば、

　斐 に （n より 一 を引きたる）を奉りたる を 甲 と云ふ。
　斐 に （n より 二 を引きたる）を奉りたる を 乙 と云ふ。

業終はりぬ。

繰り返し終はりぬ。
```

### 6.8 配列の各々反復

## 7. 影詞（GLSL fragment shader）モード

ファイル拡張子 `.kg`。同じ字句解析・構文解析を共有、出力先のみ JS から GLSL ES 1.00 に切替。CLI コマンド：`wabun compile-影詞 file.kg -o file.frag`。

### 7.1 影詞での約束
- 業「主」を必ず1つ定義。引数なしで vec4 を返す純粋関数
- 業「主」の戻り値が `gl_FragColor` に代入される
- 組み込み入力 uniform：
  - `uv`（vec2、画素正規化座標 [0,1]^2）
  - `時`（float、経過秒）
  - `解像度`（vec2、画素単位）

### 7.2 ベクトル型
| 書き方 | 型 |
|---|---|
| 数値リテラル | float |
| `〔a、b〕` | vec2 |
| `〔a、b、c〕` | vec3 |
| `〔a、b、c、d〕` | vec4 |

### 7.3 swizzling（成分参照）
| 書き方 | GLSL |
|---|---|
| `v の「横」` | v.x |
| `v の「縦」` | v.y |
| `v の「奥」` | v.z |
| `v の「四」` | v.w |
| `v の「赤」` | v.r |
| `v の「緑」` | v.g |
| `v の「青」` | v.b |
| `v の「不透明」` | v.a |
| `v の N 番目` | v[N-1]（1始まり、N がリテラルなら静的） |

### 7.4 影詞専用の業
| 業名 | GLSL |
|---|---|
| `混ぜ` | mix(a, b, t) |
| `端` | clamp(x, lo, hi) |
| `滑らか段` | smoothstep(e0, e1, x) |
| `分数` | fract |
| `歩` | step(edge, x) |
| `長さ` | length |
| `正規化` | normalize |
| `内積` | dot |
| `外積` | cross（vec3のみ） |
| `距離` | distance |
| `反射` | reflect |

### 7.5 影詞の最小例（虹色グラデーション）
```
受けて返す業を 主 と云ふ。
　時 に 〇・五 を掛けたる を t と云ふ。
　〔
　　正弦 に （uv の「横」 に t を加へたる）を奉りたる、
　　余弦 に （uv の「縦」 に t を加へたる）を奉りたる、
　　〇・五、
　　一
　〕 を返すなり。
業終はりぬ。
```

### 7.6 影詞では禁止
副作用全般：`書きけり`／`問ひけり`／集合・録の改む系・削る系／`末尾追加` 等／`投ぐ`／`試みに`／`読み入れけり`／録直書／各々反復／条件反復／範囲反復（数値リテラル上下限以外）。

## 8. LLM への指示テンプレ（コピペ用）

```
あなたは和文 (wabun-lang) というプログラミング言語に熟練したコーダーです。
以下のルールに完全に従って、和文でコードを書いてください。

絶対規則：
1. すべての文の終端は全角句点「。」
2. 文字列リテラルは「〜」（鉤括弧）
3. 識別子（変数名・業名）は鉤括弧で囲まない
4. 配列リテラルは〔 〕、録（連想配列）は 録：…、録終はり
5. 業（関数）の引数で複合式を使うときは必ず全角括弧（）で囲む
6. ブロックは終端マーカー（然らば終はり／繰り返し終はりぬ／業終はりぬ／試み終はりぬ）で閉じる
7. 比較式は左右を読点「、」で区切る（例：値、五に等し）
8. 配列インデックスは 1 始まり（配列 の 一 番目 が最初の要素）
9. 数値は漢数字推奨（一、二、…、京、三・一四 で 3.14）
10. 業の呼び出しは「名 に 引数 を奉りたる」（式）または「名 に 引数 を奉りけり」（文）

構文の基本：
- 変数宣言：〈式〉を 名 と云ふ。
- 再代入：名 に 〈式〉を改む。
- 出力：〈式〉を書きけり。
- 条件分岐：〈条件〉ならば、〈処理〉然らば終はり。
- 範囲反復：〈始〉より〈終〉まで 名 を一つずつ増しつつ、〈処理〉繰り返し終はりぬ。
- 業定義：引数 を受けて返す業を 名 と云ふ。〈処理〉〈式〉を返すなり。業終はりぬ。

算術（左結合、優先順位は全角括弧で）：
- A に B を加へたる ＝ A + B
- A より B を引きたる ＝ A - B
- A に B を掛けたる ＝ A * B
- A を B にて 割りたる ＝ A / B

主な標準ライブラリ：
- 数値：絶対値／平方根／最大／最小／冪／正弦／余弦／円周率／自然底
- 文字列：部分／逆順／含む／結ぶ／分かつ／整ふ／置換
- 配列：並べ替へ／降順／末尾追加／空
- 高階：写し替へ（map）／選び出し（filter）／束ね（reduce）／巡らす（forEach）
- 変換：数値化（漢数字も解釈）／文字列化／型

書いた後、コードに対して注釈（※〜※）で意図を補足してください。
