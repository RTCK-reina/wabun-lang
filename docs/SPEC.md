# 和文 (wabun-lang) 言語仕様書

Version 0.1.0
Author: RTCK

## 0. 思想

wabun-lang は古典日本語（文語体）の文法をそのまま構文として用いる難解言語である。漢文ベースの先行例 wenyan-lang の和文版に相当する。係り結び・助動詞・助詞による格表示を構文要素として写し取り、コードがそのまま擬古文として読めることを目標とする。

実装方針は翻訳方式とし、目的言語は JavaScript とする。Node.js による卓上実行と、閲覧器での単一ファイル・遊び場の両形態を提供する。

## 1. 字句

### 1.1 ホワイトスペースと文区切り

- 半角・全角の空白、タブ、改行は字句区切りとして扱う。
- `。`（句点）は文の終端である。
- `、`（読点）は式・引数の区切りである。
- インデントは構文上の意味を持たない（可読性のためにのみ用いる）。

### 1.2 コメント

- `※` から行末までを注釈として扱う。
- 例：`※ これは注釈なり ※`

### 1.3 数値リテラル

漢数字を用いた自然数リテラルを採用する。半角アラビア数字 `0-9` も同義として受理する。

| 字 | 値 |
|----|----|
| 〇 / 零 | 0 |
| 一 | 1 |
| 二 | 2 |
| 三 | 3 |
| 四 | 4 |
| 五 | 5 |
| 六 | 6 |
| 七 | 7 |
| 八 | 8 |
| 九 | 9 |
| 十 | 10 |
| 百 | 100 |
| 千 | 1000 |
| 万 | 10000 |

合成規則は古典的な日本語の数詞に従う。例：

- `二十三` → 23
- `百二十三` → 123
- `三千五百` → 3500
- `一万二千三百四十五` → 12345

負数は接頭辞 `負の` を用いる。例：`負の三` → -3。

小数は `三・一四` のように中黒で区切る（例：3.14）。

### 1.4 文字列リテラル

鉤括弧 `「」` で囲む。入れ子はサポートしない。

- 例：`「こんにちは、世界」`

### 1.5 真偽値リテラル

- `真` … true
- `偽` … false

### 1.6 nilリテラル

- `無し` … null

### 1.7 識別子

変数名・関数名は鉤括弧 `「」` で囲んで参照する。同じ字面で文字列リテラルと衝突するが、出現位置（助詞 `を` `に` `と云ふ` 等）から構文的に判別する。慣習として、変数を初出させるときは `「名」と云ふ` の形で導入し、以後は `「名」` で参照する。

例：

- `三を「年齢」と云ふ。`
- `「年齢」を書きけり。`

### 1.8 予約語

下記の語は構文要素として用いられ、識別子（鉤括弧内の名前）としては推奨されないが衝突は文脈で解決される：

`真`, `偽`, `無し`, `負の`, `云ふ`, `改む`, `加ふ`, `引く`, `掛く`, `割る`, `余り`, `等し`, `異なり`, `大なり`, `小なり`, `劣らず`, `勝らず`, `且つ`, `或いは`, `非ず`, `書きけり`, `詠みけり`, `問ひけり`, `ならば`, `然らば`, `然らずば`, `然らずして`, `終はり`, `繰り返し`, `終はりぬ`, `間`, `増しつつ`, `減じつつ`, `各々`, `為して`, `業`, `受けて`, `返す`, `返すなり`, `奉る`, `番目`, `数`, `継ぐ`, `長さ`, `集ひ`, `より`, `まで`, `を`, `に`, `と`, `の`, `は`, `の間`

## 2. 演算

### 2.1 算術

| 構文 | 意味 |
|------|------|
| `〈A〉に〈B〉を加へたる` | A + B |
| `〈A〉より〈B〉を引きたる` | A - B |
| `〈A〉に〈B〉を掛けたる` | A × B |
| `〈A〉を〈B〉にて割りたる` | A / B |
| `〈A〉を〈B〉にて割りたる余り` | A mod B |

連鎖：`三に四を加へたるを五に掛けたる` → (3+4)*5 = 35

### 2.2 比較

| 構文 | 意味 |
|------|------|
| `〈A〉〈B〉に等し` | A === B |
| `〈A〉〈B〉に異なり` | A !== B |
| `〈A〉〈B〉より大なり` | A > B |
| `〈A〉〈B〉より小なり` | A < B |
| `〈A〉〈B〉に劣らず` | A >= B |
| `〈A〉〈B〉に勝らず` | A <= B |

### 2.3 論理

| 構文 | 意味 |
|------|------|
| `〈A〉、且つ〈B〉` | A && B |
| `〈A〉、或いは〈B〉` | A \|\| B |
| `〈A〉に非ず` | !A |

### 2.4 文字列・配列操作

| 構文 | 意味 |
|------|------|
| `〈A〉に〈B〉を継ぎたる` | 文字列連結 / 配列連結 |
| `〈文字列〉の長さ` | 文字数 |
| `〈配列〉の数` | 要素数 |
| `〈配列〉の〈n〉番目` | n番目要素（1始まり） |

## 3. 文

### 3.1 変数宣言

```
〈式〉を「名」と云ふ。
```

例：`三を「年齢」と云ふ。` → `let 年齢 = 3;`

### 3.2 再代入

```
「名」に〈式〉を改む。
```

例：`「年齢」に四を改む。` → `年齢 = 4;`

### 3.3 出力

```
〈式〉を書きけり。
〈式〉を詠みけり。  ※「詠みけり」は意味的には書きけりと同義※
```

例：`「世界」を書きけり。` → `console.log("世界");`

### 3.4 入力

```
「名」に問ひけり。
```

卓上実行時は標準入力から1行受け取り、閲覧器実行時は `prompt()` を用いる。受け取った値は文字列として変数に格納される。

### 3.5 条件分岐（係り結びベース）

最小形：

```
〈条件〉ならば、
　〈処理〉
然らば終はり。
```

else 付き：

```
〈条件〉ならば、
　〈処理1〉
然らずば、
　〈処理2〉
然らば終はり。
```

else if（多段）：

```
〈条件1〉ならば、
　〈処理1〉
然らずして〈条件2〉ならば、
　〈処理2〉
然らずば、
　〈処理3〉
然らば終はり。
```

### 3.6 反復

#### 3.6.1 範囲ループ

```
〈始〉より〈終〉まで「i」を一つずつ増しつつ、
　〈処理〉
繰り返し終はりぬ。
```

`増しつつ` を `減じつつ` にすると逆方向（〈始〉が〈終〉以上であることが前提）。

意味：始 ≤ i ≤ 終 を満たす i について順に実行する（両端含む）。

#### 3.6.2 条件ループ

```
〈条件〉なる間、
　〈処理〉
繰り返し終はりぬ。
```

#### 3.6.3 配列イテレーション

```
「配列」の各々を「要素」と為して、
　〈処理〉
繰り返し終はりぬ。
```

### 3.7 関数定義

```
「引数1」と「引数2」を受けて返す業を「関数名」と云ふ。
　〈処理〉
　〈式〉を返すなり。
業終はりぬ。
```

引数なし：

```
受けて返す業を「関数名」と云ふ。
　〈処理〉
業終はりぬ。
```

### 3.8 関数呼び出し

```
「関数名」に〈引数1〉と〈引数2〉を奉る
```

戻り値を変数に格納：

```
「関数名」に〈引数〉を奉りたるを「結果」と云ふ。
```

文として呼ぶ場合：

```
「関数名」に〈引数〉を奉りけり。
```

### 3.9 配列リテラル

```
〔値、値、値〕
```

または：

```
集ひ：値、値、値、終はり
```

例：

- `〔一、二、三〕を「数々」と云ふ。`
- `集ひ：「春」、「夏」、「秋」、「冬」、終はりを「四季」と云ふ。`

### 3.10 配列追加

```
〈配列〉に〈値〉を加ふ。
```

### 3.10.1 要素更新

```
〈配列〉の〈n〉番目に〈値〉を改む。
〈録〉の「キー」に〈値〉を改む。
```

### 3.10.2 要素削除

```
〈配列〉の〈n〉番目を削る。
〈録〉の「キー」を削る。
```

### 3.10.3 例外処理

```
試みに、
　〈処理〉
過つに、〈名〉を以て、
　〈処理〉
試み終はりぬ。
```

`〈名〉を以て、` は省略可。捕捉した例外は既定で `過ち` として参照できる。例外を投げるには：

```
〈式〉を投ぐ。
```

### 3.10.4 モジュール読み入れ

```
「相対パス」を読み入れけり。
```

指定経路のファイルを字句解析・構文解析した上で、現在の構文木にそのまま展開する。循環読み入れは検出して2回目以降を無視する。卓上（`wabun run`）でのみ動作。閲覧器の遊び場では未対応。

### 3.11 レコード（録）リテラル

連想配列。文字列キーを取る。

```
録：「キー」は〈値〉、「キー」は〈値〉、録終はり
```

例：

```
録：「名」は「太郎」、「年」は二十、録終はり を 人 と云ふ。
人 の「名」を書きけり。   ※ 太郎 ※
人 の「年」を書きけり。   ※ 20  ※
```

### 3.12 グルーピング括弧

式の優先順位を明示するため `（）` を用いる。半角 `()` も同義。

```
（三 に 四 を加へたる）に 五 を掛けたる を書きけり。   ※ 35 ※
三 に （四 に 五 を掛けたる）を加へたる を書きけり。   ※ 23 ※
```

## 3.13 標準ライブラリ（組み込み関数・組み込み定数）

関数は `名 に 引数 を奉りたる`（式）／`名 に 引数 を奉りけり`（文）で呼び出す。定数は単純に名前で参照する。

### 数値・数学

| 名前 | 引数 | 戻り値 |
|------|------|--------|
| `絶対値` | 数 | 絶対値 |
| `平方根` | 数 | 平方根 |
| `切り捨て` / `切り上げ` / `四捨五入` | 数 | 整数化 |
| `最大` / `最小` | 配列または可変長引数 | 最大／最小値 |
| `冪` | 底, 指数 | 底^指数 |
| `対数` | 値, 底 | 底省略時は常用対数 |
| `自然対数` | 値 | ln(値) |
| `正弦` / `余弦` / `正接` | 角(rad) | sin/cos/tan |
| `円周率` | （定数） | π |
| `自然底` | （定数） | e |

### 乱数

| 名前 | 引数 | 戻り値 |
|------|------|--------|
| `乱数` | なし | 0以上1未満の浮動小数 |
| `乱整数` | 上限 | 0以上 上限未満の整数 |

### 文字列

| 名前 | 引数 | 戻り値 |
|------|------|--------|
| `部分` | 文字列, 開始(1始), 終了 | 部分文字列 |
| `逆順` | 配列または文字列 | 逆順化 |
| `含む` | 配列または文字列, 検索値 | 真／偽 |
| `結ぶ` | 配列, 区切り | 連結文字列 |
| `分かつ` | 文字列, 区切り | 配列 |
| `整ふ` | 文字列 | 前後空白を除去 |
| `冒頭` | 文字列, 接頭辞 | 真／偽 |
| `末尾` | 文字列, 接尾辞 | 真／偽 |
| `探す` | 文字列, 検索値 | 1始の位置（0は不在） |
| `大文字化` / `小文字化` | 文字列 | 大／小文字化 |
| `置換` | 文字列, 旧, 新 | 全置換結果 |

### 配列

| 名前 | 引数 | 戻り値 |
|------|------|--------|
| `並べ替へ` / `降順` | 配列 | ソート結果 |
| `末尾追加` | 配列, 値 | 配列（破壊的） |
| `末尾除去` / `先頭除去` | 配列 | 取り除いた値（破壊的） |
| `先頭追加` | 配列, 値 | 配列（破壊的） |
| `空` | 任意 | 空かどうかの真偽 |

### 高階関数

すべて第2引数に関数を取る。

| 名前 | 相当 | 戻り値 |
|------|------|--------|
| `写し替へ` | map | 各要素を変換した新配列 |
| `選び出し` | filter | 条件を満たす要素のみの新配列 |
| `束ね` | reduce | 第3引数を初期値に畳み込む |
| `巡らす` | forEach | なし |
| `一切` | every | 全て満たすかの真偽 |
| `孰れか` | some | 一つでも満たすかの真偽 |

### レコード

| 名前 | 引数 | 戻り値 |
|------|------|--------|
| `鍵列挙` | 録 | キーの配列 |
| `値列挙` | 録 | 値の配列 |

### 日付・時刻

| 名前 | 引数 | 戻り値 |
|------|------|--------|
| `今` | なし | UNIXミリ秒 |
| `日付` | なし | YYYY/MM/DD 文字列 |
| `時刻` | なし | HH:MM:SS 文字列 |

### 変換

| 名前 | 引数 | 戻り値 |
|------|------|--------|
| `数値化` | 文字列 | 数（漢数字も解釈する） |
| `文字列化` | 任意 | 表示用文字列 |
| `型` | 任意 | 「数」「文字列」「真偽」「集」「録」「業」「空」「不明」のいずれか |

## 4. プログラム構造

プログラムは1個以上の文の列である。最上位レベルにスコープが1つあり、関数本体は別のスコープを成す。変数のスコープはレキシカルである。

## 5. 実行モデル

- wabun-lang ソースは構文木に変換され、構文木は JavaScript ソースに翻訳される。生成された成果文は Node.js もしくは閲覧器で実行される。
- 識別子は内部的にユニークな英数字名へエスケープされる（例：`年齢` → `_v_年齢` のような前置き）。
- ランタイムライブラリは `__wabun__` というオブジェクトを通じて組み込み関数（`書きけり` 等）を提供する。

## 6. エラー

字句エラー、構文エラー、実行時エラーは行番号付きで報告される。文語的なメッセージは目指さない（実用性優先）。

## 7. 例：FizzBuzz

```
一より十五まで「数」を一つずつ増しつつ、
　「数」を三にて割りたる余り、〇に等し、且つ「数」を五にて割りたる余り、〇に等しならば、
　　「FizzBuzz」を書きけり。
　然らずして「数」を三にて割りたる余り、〇に等しならば、
　　「Fizz」を書きけり。
　然らずして「数」を五にて割りたる余り、〇に等しならば、
　　「Buzz」を書きけり。
　然らずば、
　　「数」を書きけり。
　然らば終はり。
繰り返し終はりぬ。
```

## 8. 例：階乗

```
「n」を受けて返す業を「階乗」と云ふ。
　「n」、一に勝らずならば、
　　一を返すなり。
　然らば終はり。
　「n」より一を引きたるを「階乗」に奉りたるを「下」と云ふ。
　「n」に「下」を掛けたるを返すなり。
業終はりぬ。

「階乗」に十を奉りたるを書きけり。
```
