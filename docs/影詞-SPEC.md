# 影詞（かげことば）言語仕様書

> Shader = to shade（陰影をつける）の直訳。和文 (wabun) のサブセット＋ベクトル拡張で記述し、GLSL ES 1.00 fragment shader に翻訳する。

Version 0.1.0
Author: RTCK

## 0. 思想

影詞は和文 (wabun-lang) の派生言語であり、字句解析・構文解析を完全に共有する。違いはバックエンドのみ：和文が JavaScript に翻訳されるのに対し、影詞は GLSL fragment shader に翻訳される。

ファイル拡張子は `.kg`。同じ `.wb` 文法で書いた純粋計算ロジックを `.kg` として保存することで、影詞バックエンドを呼び出す。CLI は `wabun compile-影詞 file.kg -o file.frag`。

## 1. 入力（uniform）

すべての影詞プログラムは以下を組み込み変数として参照できる。これらは GLSL の uniform に対応する。

| 和文名 | GLSL 型 | 意味 |
|---|---|---|
| `uv` | vec2 | 画素の正規化座標 [0, 1]^2 |
| `時` | float | 経過秒（プレビューが起動してから） |
| `解像度` | vec2 | 描画領域の幅×高さ（画素単位） |

## 2. 出力

影詞プログラムは **業 `主`** を必ず一つ定義する。`主` は引数なしで vec4 を返す純粋関数で、その戻り値が `gl_FragColor` に代入される。

```
受けて返す業を 主 と云ふ。
　〔uv の「横」、uv の「縦」、零・五、一〕 を返すなり。
業終はりぬ。
```

## 3. 型

| 和文表現 | GLSL 型 | 由来 |
|---|---|---|
| 数値リテラル `三・一四` | float | 数値直書 |
| 〔a、b〕 | vec2 | 集合直書、要素2 |
| 〔a、b、c〕 | vec3 | 集合直書、要素3 |
| 〔a、b、c、d〕 | vec4 | 集合直書、要素4 |
| `真` / `偽` | bool | 真偽直書 |

型推論は右辺から行う。`〈式〉を 名 と云ふ。` の `名` は右辺の型を継承する。

## 4. 成分参照（Swizzling）

vec の成分参照は録（レコード）の鍵参照と同じ構文を流用する。

| 和文 | GLSL | 意味 |
|---|---|---|
| `v の「横」` | `v.x` | x 成分 |
| `v の「縦」` | `v.y` | y 成分 |
| `v の「奥」` | `v.z` | z 成分 |
| `v の「四」` | `v.w` | w 成分 |
| `v の「赤」` | `v.r` | r 成分（= x） |
| `v の「緑」` | `v.g` | g 成分（= y） |
| `v の「青」` | `v.b` | b 成分（= z） |
| `v の「不透明」` | `v.a` | a 成分（= w） |

## 5. 演算

算術・比較・論理は和文と同じ。GLSL ES 1.00 の演算子に直接翻訳される。vec と float の混在演算は GLSL の規則どおり：vec * float は要素ごとにスカラー倍される。

## 6. 制御構造

許可：

- 業（純粋関数）の宣言と呼び出し
- 条件分岐（`〜ならば、… 然らずば、… 然らば終はり。`）
- 範囲反復（`一より N まで i を一つずつ増しつつ、…`、ただし N は数値リテラルのみ）

禁止：

- `〜なる間`（while ループ）
- `〜各々`（forEach、配列が動的長になるため）
- `〜に問ひけり`（入力）
- `書きけり` / `詠みけり`（出力）
- 集合の要素更新・削除・先頭/末尾追加除去（破壊的操作）
- 録の宣言・参照（GLSL に対応物がない）
- `投ぐ` / `試みに`（例外、GPU で意味を持たない）
- `読み入れけり`（モジュール、影詞ではサブセット故に未対応）

## 7. 組み込みの業

和文の標準ライブラリのうち、GLSL に対応物があるものはそのまま使える。新たに影詞専用の業を追加する。

### 算術・三角関数（既存と同名）

| 和文 | GLSL |
|---|---|
| 絶対値 | abs |
| 平方根 | sqrt |
| 切り捨て | floor |
| 切り上げ | ceil |
| 最大 | max |
| 最小 | min |
| 冪 | pow |
| 自然対数 | log |
| 正弦 / 余弦 / 正接 | sin / cos / tan |
| 円周率 | 3.14159265… として展開 |

### 影詞専用の業

| 和文 | GLSL | 意味 |
|---|---|---|
| `混ぜ` | mix(a, b, t) | a と b を t で線形補間 |
| `端` | clamp(x, lo, hi) | x を [lo, hi] にクランプ |
| `滑らか段` | smoothstep(e0, e1, x) | エルミート補間段差 |
| `分数` | fract | 小数部 |

## 8. 翻訳例

### 入力

```
※ 虹色グラデーション ※
受けて返す業を 主 と云ふ。
　時 を 〇・五 にて 掛けたる を t と云ふ。
　〔
　　uv の「横」 に t を加へたる を 正弦 に奉りたる、
　　uv の「縦」 に t を加へたる を 余弦 に奉りたる、
　　〇・五、
　　一
　〕 を返すなり。
業終はりぬ。
```

### 出力（GLSL ES 1.00）

```glsl
precision highp float;

uniform vec2 解像度;
uniform float 時;

vec4 主() {
  float t = 時 * 0.5;
  return vec4(
    sin(uv().x + t),
    cos(uv().y + t),
    0.5,
    1.0
  );
}

vec2 uv() {
  return gl_FragCoord.xy / 解像度;
}

void main() {
  gl_FragColor = 主();
}
```

`uv` は組み込み関数として `gl_FragCoord.xy / 解像度` を返すよう自動生成される。

## 9. 制限と将来課題

- mat（行列）型未対応：vec のみ
- if 内での return 制限：GLSL ES 1.00 の制約に従う
- texture（テクスチャ参照）未対応：将来 `画 に問ひけり` のような構文で導入予定
- 複数パス（複雑なシェーダ）は未対応：1パスのフラグメントシェーダのみ
